# Philippe's project
# https://philippe-bn.github.io/cart263/projects/project-1/
That project was really cool. I liked how the simplicity of the design, which helped me to focus on the code itself. The little colorful things that move around reminded me of either fishes, or bombs. 
The usage of mouseMove was really fun, because usually, when using it, the objects that are influenced by the position of the mouse, move with the mouse. In this project, the objects are moving towards the mouse. What I noticed when playing was that when I would right, left, up, or down, they would replicate the same movement. However, when I put the mouse somewhere in the middle of the screen, and made them all move towards one another, at impact, they would automaticall change directions, and go to a position that was no longer influenced by the mouse.
